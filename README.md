# NeuralRetail

AI-powered retail analytics platform.

## Features

- Demand forecasting
- Customer churn prediction
- Inventory optimization
- MLOps dashboard
- FastAPI backend
- Streamlit frontend

## Run Project

### Install

pip install -r requirements.txt

### Run Dashboard

streamlit run app/streamlit_app.py

### Run API

python -m uvicorn api.main:app --reload
